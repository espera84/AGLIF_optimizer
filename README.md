This repository contains the updated version of optimization code implemented for the parametrization of the AGLIF model available at this modeldb url:

https://modeldb.science/267598

**Code authorship**: *Emiliano Spera*

**Reference scientific article**: *Marasco A, Spera E, De Falco V, Iuorio A, Lupascu CA, Solinas S, Migliore M. An Adaptive Generalized Leaky Integrate-and-Fire Model for Hippocampal CA1 Pyramidal Neurons and Interneurons. Bull Math Biol. 2023 Oct 4;85(11):109. doi: 10.1007/s11538-023-01206-8. PMID: 37792146; PMCID: PMC10550887.*

The code available here represent and improvement of the previous release according to the following point:

-	faster optimization time
- code refactoring and comments
